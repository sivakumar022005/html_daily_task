# 🎬 Shahrukh Khan Biography Website

A simple **HTML-based biography website** created to showcase the life, career, achievements, family details, and media content of Bollywood actor **Shah Rukh Khan**.

## 📌 Project Overview

This project is a basic web development project using **HTML**. It contains two interconnected pages:

* **Biography Page** – Contains information about Shah Rukh Khan, his career, movies, awards, and family members.
* **Channel Page** – Contains information about Bollywood Hungama along with video and audio elements.

## 🛠️ Technologies Used

* HTML5
* Tables
* Images
* Hyperlinks
* Ordered Lists
* Video Element
* Audio Element
* Basic HTML Formatting

## ✨ Features

### 👤 Biography Page

* Shah Rukh Khan biography
* Early life and background
* Film career information
* Movie details
* Family members
* Movie collection table
* Profile image
* Link to Channel page

### 📺 Channel Page

* Bollywood Hungama information
* Embedded video player
* Embedded audio player
* HTML5 multimedia elements

## 🔗 Page Navigation

The Biography page contains a link to the Channel page using an HTML hyperlink.

```html
<a href="khan.html">Channel</a>
```

## 🎯 Purpose

The main purpose of this project is to practice fundamental **HTML concepts**, including:

* Headings and paragraphs
* Images
* Links
* Tables
* Lists
* Audio and video embedding
* Page-to-page navigation

## 🚀 How to Run

1. Clone or download this repository.
2. Keep all HTML, image, video, and audio files in the appropriate project folder.
3. Open the main HTML file in any modern web browser.
4. Use the **Channel** link to navigate between pages.
